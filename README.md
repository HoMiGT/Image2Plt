# image2plt

一个用 Rust 编写的高性能图像转 PLT (HP-GL) 矢量格式工具。

## 为什么写这个工具？

可批量转换图片到标准的 `.plt` (HP-GL) 指令文件。

## 主要特点

- **贼快**：底层用了 Rust 加上 `rayon` 做多线程并发，只要你的 CPU 核心够多，批量转换就是瞬间的事。
- **化繁为简**：自带了大津法 (Otsu) 自适应二值化和高斯去噪；纯黑白图像跳过模糊，保留细线和缺口。
- **保留形状**：沿黑色像素方格的外边界提取闭合轮廓，默认只合并共线点，保留凹角和孔洞。需要近似平滑时可开启 RDP (Ramer-Douglas-Peucker) 折线简化。
- **实心填充**：默认将闭合的黑色区域填实，不额外描边，白色缺口和孔洞保持空白；也可切换为仅绘制轮廓。
- **开箱即用**：随便跑一下，它就会自己在当前目录建好 `input` 和 `output` 文件夹，顺带生成一个 `config.toml` 配置模板。

## 怎么用？

1. 编译好程序后（或者直接拿现成的二进制包），在终端里直接运行一次。
2. 程序会自动生成 `input` 目录和 `config.toml` 配置文件。
3. 把你需要转换的图片（支持 png, jpg, bmp, webp 等常见格式）一股脑扔进 `input` 文件夹里。
4. 再运行一次程序，坐等它刷屏。
5. 去 `output` 文件夹里拿你的 `.plt` 矢量文件吧！

## 高级配置

第一次运行生成的 `config.toml` 可以自己按需调整。几个比较关键的参数：

- **反转颜色** (`invert`)：默认 `false`，提取黑色区域；设为 `true` 时提取白色区域。
- **RDP 容差** (`rdp_epsilon`)：默认 `0.0`，仅合并共线点，精确保留像素形状。正值启用近似简化，值越大可能丢失越多细节；像 `[[1,1],[1,0]]`（1 为黑色）的 L 形缺口应使用 `0.0`。已有配置也需要将原先的 `1.0` 改为 `0.0`。
- **最小轮廓周长** (`min_points`)：按简化前的像素边数过滤短轮廓，不按最终拐点数过滤。
- **物理尺寸** (`output_width_mm`)：你可以直接设定输出的实际物理宽度（毫米），程序会自动帮你换算成 HP-GL 的内部单位（默认 1 mm = 40 units）。
- **区域填充** (`[plt]` 中的 `fill`)：默认 `true`，以当前画笔实心填充闭合区域（默认 1 号黑色笔）。设为 `false` 可恢复仅绘制轮廓。填充使用 `PM`、`FT1`、`FP0` 指令，查看器或设备需要支持多边形填充；只支持 `PU/PD` 的设备应使用轮廓模式。

## 工作原理

简单来说，代码的工作流就是标准的图像处理流水线：

1. **预处理**：转灰度 -> 非纯黑白图像做高斯去噪 -> 二值化，将目标颜色设为前景。
2. **提取轮廓**：将前景像素视为单位方格，去掉相邻前景的公共边，追踪外边界和孔洞；仅对角接触的黑格保持各自的边界。
3. **精简路径**：合并共线点；`rdp_epsilon > 0` 时再用 RDP 做近似简化。
4. **生成指令**：转换坐标系，用 `PU`（抬笔）、`PD`（落笔）描述路径；填充模式将所有闭合轮廓存为同一组多边形，用奇偶规则保留内部孔洞后实心填充，不执行额外的轮廓描边。指令定义见 [HP-GL/2 技术手册，第 21、22 章](https://www.hp.com/ctg/Manual/bpl13211.pdf)。
