# image2plt

一个用 Rust 编写的高性能图像转 PLT (HP-GL) 矢量格式工具。

## 为什么写这个工具？

如果你平时跟刻字机、激光雕刻机、裁床或者老式绘图仪打交道，肯定知道它们往往只认矢量路径。市面上很多带界面的大软件确实能搞定图片转矢量的活儿，但如果你有一大批图片（比如几十上百张）需要快速批量处理，手动去点就太折磨人了。

所以我就搓了这个专门用来批处理的小工具。它特别适合处理黑白线稿或者边缘轮廓清晰的图片，能全自动地把它们提取成矢量折线，然后打包输出成标准的 `.plt` (HP-GL) 指令文件。直接把生成的文件扔给机器就能画了。

## 主要特点

- **贼快**：底层用了 Rust 加上 `rayon` 做多线程并发，只要你的 CPU 核心够多，批量转换就是瞬间的事。
- **化繁为简**：自带了大津法 (Otsu) 自适应二值化和高斯去噪，不用你每张图去死磕阈值。
- **智能平滑**：提取出来的路径用了 RDP (Ramer-Douglas-Peucker) 算法做折线简化。通俗点说，就是在不影响整体形状的前提下，把没必要的、密密麻麻的点给干掉，这样切割机走刀的时候会更顺滑，不会一直抖。
- **开箱即用**：随便跑一下，它就会自己在当前目录建好 `input` 和 `output` 文件夹，顺带生成一个 `config.toml` 配置模板。

## 怎么用？

1. 编译好程序后（或者直接拿现成的二进制包），在终端里直接运行一次。
2. 程序会自动生成 `input` 目录和 `config.toml` 配置文件。
3. 把你需要转换的图片（支持 png, jpg, bmp, webp 等常见格式）一股脑扔进 `input` 文件夹里。
4. 再运行一次程序，坐等它刷屏。
5. 去 `output` 文件夹里拿你的 `.plt` 矢量文件吧！

## 高级配置

第一次运行生成的 `config.toml` 可以自己按需调整。几个比较关键的参数：

- **反转颜色** (`invert`)：看你机器是刻黑线还是留白，可以随时翻转提取逻辑。
- **RDP 容差** (`rdp_epsilon`)：这个值决定了路径化简的强度。值越大，点越少，走线越平滑（但也可能会丢失细节棱角）；值越小，保留的细节越多。建议根据你的机器精度微调。
- **物理尺寸** (`output_width_mm`)：你可以直接设定输出的实际物理宽度（毫米），程序会自动帮你换算成 HP-GL 的内部单位（默认 1 mm = 40 units）。

## 工作原理

简单来说，代码的工作流就是标准的图像处理流水线：
1. **预处理**：彩色图转灰度 -> 高斯模糊抹平小噪点 -> 计算最佳阈值变成纯黑白。
2. **提取轮廓**：用 Suzuki 算法去扣所有连通块的边界。
3. **精简路径**：拿着一堆密集的边缘点，用 RDP 算法做直线拟合化简。
4. **生成指令**：把坐标系转换好，翻译成绘图仪能听懂的 `PU`（抬笔）、`PD`（落笔）等指令。
